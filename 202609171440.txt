⏺ Found and fixed the thing blocking everything — #1973.

  A Windows-only test failure was sitting on master, so every PR branched from
  it was red. #1966 and #1970 were both failing for it, neither having touched
  the provisioner.

  The cause: TestRequireProvisioner_501SaysWhichStateItIsIn asserts the 501 body
  names the token path, but the body is JSON — so on Windows the backslashes
  arrive doubled and the raw path isn't a substring. On Linux and macOS the
  separator is /, which JSON doesn't escape, so it passed on every developer
  machine and two of the three CI platforms.

  Since I have no Windows runner, I reproduced the failure on any platform
  rather than reasoning about it: same JSON body from a Windows-style path,
  asserting the raw path is absent (a premise check — if it were present, the
  test wouldn't be reproducing the defect), the encoded path is present, and a
  POSIX path encodes to itself so the fix changes nothing where things already
  worked.

  Worth being straight about the class: no gate would have caught this. #1922's
  platform_sensitive guard worked correctly, pkg/server is in the matrix, and
  the test ran on Windows and failed honestly. Nothing was missing — the
  assertion was just written against a POSIX assumption. A reviewer asking "does
  this survive backslashes in JSON?" would have caught it; a gate wouldn't.

  One decision for you, flagged by the agent

  Auto-upgrade replaces the binary on disk but the running session continues on 
  the old version. It read "self-upgrade and continue" as "continue into opening
  the tunnel", not "continue on the new version".

  Re-execing would mean running a freshly-written client binary — which is
  exactly the pattern that caused the three EDR reinstalls, so it deliberately
  didn't ship that unexercised. If you meant "restart into the new version", it
  needs adding on purpose with a way to test it.

  My view: what it built is the safer reading. A user who opts into auto-upgrade
  gets the new binary on their next start, which is a day away at most, and
  nothing mid-session is disturbed.
