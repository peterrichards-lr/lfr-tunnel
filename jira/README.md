# jira/

Upstream Liferay DXP bug reports and platform-limitation writeups tracked
alongside this codebase. See [`.agents/skills/jira_tracker/SKILL.md`](../.agents/skills/jira_tracker/SKILL.md)
for the naming conventions, template, and lifecycle this directory follows.

- `todo/` — drafted but not yet raised on the JIRA platform.
- `open/` — raised and currently open on JIRA.
- `closed/` — resolved, closed, or discarded.
